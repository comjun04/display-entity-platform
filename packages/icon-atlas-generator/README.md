# icon-atlas-generator

마인크래프트의 블록 및 아이템의 아이콘을 생성하는 스크립트입니다.

DEPL 내 블록/아이템 디스플레이 추가 화면에서 단순 텍스트 대신 아이템 아이콘을 표시하도록 구조를 변경하면서, 아이템 아이콘의 필요성이 생겼습니다. 외부 서비스에서 마인크래프트 내 블록/아이템 아이콘을 자동화된 방식으로 가져오는 데는 제한사항이 많기 때문에, 자체적으로 아이템 아이콘을 생성하기 위해 직접 생성하는 방식을 사용합니다.

## 필요 환경

- Node.js 20 이상
- `pnpm` 패키지 매니저 세팅
  - 이 모노레포는 pnpm으로 관리하고 있습니다. 모노레포 셋업을 손대지 않았다면 문제되지 않습니다.
- 브라우저를 실행할 수 있는 그래픽 환경
  - Windows, Ubuntu Desktop 등의 데스크톱 환경이라면 정상적으로 사용이 가능하나, GUI가 없는 서버용 OS의 경우 추가적인 설정이 필요할 수 있습니다.

## 사용 준비

1. `.env.example` 파일을 `.env`로 복사하고, 파일을 열어 환경 변수를 수정합니다.
2. 프로젝트 루트 폴더에서 아래 명령어를 실행하여 프론트엔드를 빌드합니다.

```bash
pnpm iconatlasgen front:build
```

## 실행 방법

일반적으로 이 스크립트를 직접 실행하지 않고, asset-utils 레포 내 `generateIncremental.ts` 버전별 리소스 순차 생성 스크립트에서 아이템 아이콘 생성을 위해 이 스크립트를 pnpm을 통해 직접 호출합니다.

이 스크립트나 프론트엔드 코드 수정을 위해 직접 실행해야 할 경우, 프로젝트 루트 폴더에서 아래 명령어를 실행합니다.

```bash
pnpm iconatlasgen start <옵션>
```

사용할 수 있는 옵션은 다음과 같습니다. 필수 옵션이 누락된 경우 오류와 함께 종료됩니다.

- `-c` `--config` **(필수)**: 서버 실행에 필요한 설정 **파일**의 경로입니다. 상대경로인 경우 `packages/icon-atlas-generator` 폴더를 기준으로 합니다.
- `-o` `--out-dir`: 생성이 완료된 아이콘 아틀라스 이미지와 메타데이터 파일을 저장할 **폴더** 경로입니다. 상대경로인 경우 `packages/icon-atlas-generator` 폴더를 기준으로 합니다. 지정하지 않은 경우 `packages/icon-atlas-generator` 폴더로 설정됩니다.
- `-n` `--no-open`: 백엔드 서버 시작 시 프론트엔드 브라우저를 자동으로 실행하지 않습니다. 개발 중이거나 브라우저를 실행할 수 없는 서버 환경일 경우 사용할 수 있습니다.

## 개발

백엔드를 단독으로 실행하고자 할 경우, 위의 수동 실행 방법을 참고하여 서버를 실행합니다.
필요한 설정 파일은 asset-utils의 리소스 순차 생성 실행 중에 생성되고, `packages/asset-utils/workdir/<버전>/icon-atlas-generator-config.json`에 위치해 있습니다. 임시로 이 파일을 복사해서 사용하는 것을 권장합니다.

프론트엔드 개발 서버를 실행하려면, 프로젝트 루트 폴더에서 `pnpm iconatlasgen front:dev`를 실행합니다.
모든 프론트엔드 코드는 `src/frontend` 안에 들어 있습니다. 이 폴더 외부의 파일은 공통 타입을 제외하고 import하면 안 됩니다.
